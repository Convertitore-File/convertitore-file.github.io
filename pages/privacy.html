Privacy Policy

Ultimo aggiornamento: Novembre 2026
In sintesi: La tua privacy è totale. Nessun file che converti lascia mai il tuo dispositivo.

1. Nessun Upload di File

Convertitore File elabora ogni documento interamente nel browser del tuo utente (lato client). Quando selezioni o trascini un file, questo viene letto localmente per generare l'anteprima e la stampa PDF, senza transitare o essere memorizzato su alcun server remoto.

2. Hosting e Dati Tecnici (GitHub Pages)

Il sito è ospitato su GitHub Pages. Durante la navigazione, GitHub raccoglie autonomamente dati tecnici standard (es. indirizzo IP) nei propri log di sicurezza. Per dettagli, consulta la policy ufficiale di GitHub.

3. Utilizzo della Memoria Locale

Il sito non utilizza cookie di tracciamento o profilazione. Viene impiegata esclusivamente la memoria locale del browser (localStorage) per ricordare la tua preferenza relativa al tema grafico (chiaro o scuro).

4. Risorse di Terze Parti

Per la corretta visualizzazione grafica, il sito carica font e icone da CDN esterne affidabili (Google Fonts e Font Awesome tramite Cloudflare).
